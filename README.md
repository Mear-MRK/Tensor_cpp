# Tensor Library in C++

This project provides an implementation of a Tensor library in C++. It includes handling of multi-dimensional arrays with support for various operations and memory management techniques. The library also includes reference counting for efficient tensor views while ordinary tensor copies remain independent.


## Features

- **Tensor Class**: Supports multi-dimensional arrays with various mathematical operations.
- **Payload Class**: Manages the underlying data with reference counting and efficient memory operations.
- **Memory Management**: Includes copy constructors, move constructors, and assignment operators for efficient memory handling.
- **Optimized Contraction**: Reorders contracted axes into matrices and uses matrix multiplication.
- **Optional BLAS**: Uses a CBLAS-compatible library when enabled, with an automatic built-in fallback.
- **Debugging**: Debugging support with logging enabled via the `DEBUG` preprocessor definition.

## Performance Note

Tensor contraction moves the contracted left index to the last matrix index and the contracted right index to the first matrix index. It then performs an `M x K` by `K x N` matrix multiplication. Packing is skipped when an input is already in the required layout. The built-in matrix loop is dependency-free and single-threaded; a BLAS library can provide additional vectorization and parallelism.

## Usage

You can create a Tensor with various constructors provided:

```cpp
#include <iostream>
#include <cstdlib>
#include <complex>
#include "Tensor.hpp"

int main() {

    Tensor<double> tensor1({2, 3, 4}, 1); // Creates a 2x3x4 tensor (rank-3) of doubles initialized with 1.

    Tensor<std::complex<float>> tensor2(5); // Creates a one-dimensional tensor of size 5 of complex numbers.

    Tensor<int> tensor3({3, 3}, rand); // Creates a 3x3 tensor of random integers generated by 'int rand(void)' function.

    Tensor<int> tensor4 = Tensor<int>::range(1, 25).reshape({2, 2, 3, 2}); // Creates a tensor with a range of values [1-24] and reshapes it to 2x2x3x2.

    Tensor<> tensor5 = Tensor<float>::linspace(1, 5, 12); // Creates a one-dimensional tensor containing 12 linearly spaced numbers between 1 and 5 (inclusive).

    std::cout << tensor3.to_string() << std::endl; // Prints tensor3.

    return 0;
}
```

The library supports various operations like arithmetic operations and **tensor contraction**:

```cpp
Tensor<float> tensor1({2, 2}, 1); // 2x2 tensor initialized with 1
Tensor<float> tensor2({2, 2}, -2); // 2x2 tensor initialized with -2

tensor1[{1}] = 3; // Sets the 2nd row of tensor1 to 3

Tensor<float> result = tensor1 + tensor2; // Addition
result *= 2.0; // Multiplication by scalar

auto res = Tensor<float>::cnt(tensor1, tensor2, 1, 0); // Contraction of 2nd index of tensor1 with 1st index of tensor2
auto res2 = tensor1 % tensor2; // Matrix product
bool b = res.is_close_to(res2, 1e-7); // True

auto res3 = result.copy(); // Cloning result

res3.apply(func);  // Applying element-wise function 'float func(float)' to res3
```

Enable debugging by defining the `DEBUG` preprocessor directive:

```cpp
#define DEBUG 1
#include "Tensor.hpp"
```

## Optional BLAS Acceleration

Tensor contraction uses a built-in matrix multiplication by default. To use an available CBLAS-compatible library for `float`, `double`, `std::complex<float>`, and `std::complex<double>` tensors, define `TENSOR_USE_BLAS` and link the library when compiling:

```bash
# OpenBLAS or another CBLAS implementation
c++ -std=c++17 -DTENSOR_USE_BLAS your_program.cpp -lopenblas

# Apple Accelerate
c++ -std=c++17 -DTENSOR_USE_BLAS -DACCELERATE_NEW_LAPACK your_program.cpp -framework Accelerate
```

Other element types and matrix dimensions larger than the BLAS integer interface supports automatically use the built-in implementation.

## Tests

`Tensor_contraction_test.cpp` compares the matrix-product implementation with an independent generic contraction. It covers all contraction-axis combinations for rank-3 and rank-4 tensors, integer, floating-point and complex element types, tensor views with nonzero offsets, vector dot products, invalid dimensions, invalid axes, and empty inputs.

Run the dependency-free tests:

```bash
c++ -std=c++17 -Wall -Wextra -Wpedantic Tensor_contraction_test.cpp -o tensor_contraction_test
./tensor_contraction_test
```

Run the same tests with OpenBLAS:

```bash
c++ -std=c++17 -DTENSOR_USE_BLAS -Wall -Wextra -Wpedantic Tensor_contraction_test.cpp -lopenblas -o tensor_contraction_test
./tensor_contraction_test
```

Run them with Apple Accelerate:

```bash
c++ -std=c++17 -DTENSOR_USE_BLAS -DACCELERATE_NEW_LAPACK -Wall -Wextra -Wpedantic Tensor_contraction_test.cpp -framework Accelerate -o tensor_contraction_test
./tensor_contraction_test
```
